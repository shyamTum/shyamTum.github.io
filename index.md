## Featured Work

### SpaDiffHis: Sparse-Point Guided Diffusion for Histopathology

A diffusion-based framework for generating realistic H&E histopathology images using sparse point-map conditioning. The system uses Stable Diffusion fine-tuning, contrastive feature preservation, and post-hoc mask generation to create paired synthetic images and segmentation masks.

**Keywords:** Diffusion Models, Histopathology, Synthetic Data, Sparse Point Conditioning, Contrastive Learning, Nuclei Segmentation.

---

### Multi-Expert LLM-Guided Arbitration for Histopathology

A multimodal AI framework where multiple expert models analyze medical imaging data and an LLM-guided arbitration mechanism improves final decision-making. The goal is to improve robustness, interpretability, and reliability over single-model prediction.

**Keywords:** LLMs, Multi-Expert AI, Multimodal Learning, Histopathology, Arbitration, Interpretability.

---

### Multimodal Glioma Classification

A biomedical AI pipeline combining whole-slide histopathology images and clinical information for glioma classification and mutation prediction. The work demonstrates strong multimodal fusion performance with **AUC 0.967 / Accuracy 0.936**.

**Keywords:** WSI, Clinical Fusion, Glioma, IDH1 Mutation, Multimodal AI, Medical Imaging.

---

### Agentic RAG Platform for Scientific Workflows

A retrieval-augmented AI platform for laboratory-specific scientific documents. The system integrates vector search, LLM reasoning, LangGraph/LangChain-based agentic workflow design, and FastAPI/Gradio interfaces for scientific question answering.

**Keywords:** RAG, Agentic AI, LangGraph, LangChain, FAISS, SentenceTransformers, FastAPI, Gradio.

---

### DermPath AI Explorer

An AI-assisted dermatopathology image exploration tool for unlabeled skin histopathology images. The system processes CZI/WSI images into patches, filters background regions, extracts CLIP/DINOv2 embeddings, visualizes UMAP clusters, performs similar-patch retrieval, and supports cautious VLM/GPT-based morphology interpretation.

**Keywords:** Dermatopathology, CZI Images, CLIP, DINOv2, UMAP, Clustering, Similarity Search, VLM Interpretation.
